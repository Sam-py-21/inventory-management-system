# Inventory Management System (Python + SQLite)

This is a simple Inventory Management System built using Python and SQLite.
It helps manage products, stock, sales, purchases, analytics, and export inventory data to Excel.

## Features
- Add new products
- View all products
- Search products
- Stock In / Stock Out
- Low stock alert
- Sales & purchase records
- Analytics using NumPy
- Export inventory data to Excel

## Technologies Used
- Python
- SQLite
- NumPy
- OpenPyXL
